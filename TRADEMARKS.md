# Товарные знаки и правила использования бренда CajeerEngine

## Статус

`CajeerEngine`, название проекта, логотипы, обозначения, слоганы, имена компонентов, доменные обозначения и иные фирменные элементы используются для идентификации проекта и его официальных материалов.

Этот документ описывает правила корректного использования бренда проекта. Он не заменяет лицензию на исходный код и не предоставляет дополнительных прав на товарные знаки, названия, домены, логотипы или фирменный стиль.

## Разрешённое использование

Без отдельного письменного разрешения допускается:

- ссылаться на `CajeerEngine` как на используемое программное обеспечение;
- указывать совместимость расширения, темы, плагина или интеграции с `CajeerEngine`;
- использовать название проекта в технической документации, статьях, обзорах и обучающих материалах;
- использовать название проекта в package metadata, README и changelog, если это не создаёт впечатление официального статуса;
- писать «расширение для CajeerEngine», «тема для CajeerEngine», «интеграция с CajeerEngine».

## Запрещённое использование без разрешения

Без письменного разрешения запрещено:

- представлять сторонний продукт как официальный продукт CajeerEngine;
- использовать название CajeerEngine в названии компании, сервиса, домена или продукта так, чтобы это вводило в заблуждение;
- использовать логотипы и фирменный стиль проекта в коммерческих материалах без согласования;
- создавать впечатление партнёрства, сертификации, спонсорства или одобрения со стороны Cajeer Team, если оно не подтверждено;
- использовать бренд проекта в вредоносных, мошеннических, спамных или вводящих в заблуждение материалах;
- регистрировать сходные домены, названия, аккаунты или обозначения с целью имитации проекта.

## Формулировки для сторонних расширений

Рекомендуемые формулировки:

```text
Совместимо с CajeerEngine
Плагин для CajeerEngine
Тема для CajeerEngine
Интеграция с CajeerEngine
```

Нерекомендуемые формулировки:

```text
Официальный CajeerEngine Plugin
CajeerEngine Pro от стороннего автора
CajeerEngine Cloud от сторонней команды
```

Исключение возможно только при письменном разрешении.

Официальные коммуникации проекта должны использовать домен `cajeer.ru` или иные явно подтверждённые каналы проекта.

Контакты:

- brand@cajeer.ru — вопросы бренда и использования обозначений;
- legal@cajeer.ru — юридические вопросы;
- press@cajeer.ru — пресса и публикации;
- contact@cajeer.ru — общие обращения;
- support@cajeer.ru — поддержка;
- admin@cajeer.ru — административные вопросы;
- abuse@cajeer.ru — сообщения о злоупотреблениях.
